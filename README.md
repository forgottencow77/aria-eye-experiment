# Aria Eye UI and Mock Emotion Experiment

This repository contains the existing eye-only manual control UI and a mock-only participant experiment workflow for the Project Aria eye robot.

## Pages

- `/` — legacy servo controls
- `/simple` — simple manual controls
- `/study` — emotion presets and manual adjustment
- `/experiment/admin` — configure and create a mock experiment session
- `/experiment/participant` — participant consent, practice, presentation, and responses

The experiment engine does not call the servo or LCD APIs. Hardware preview and live experiment control remain outside this mock phase. Existing servo limits and calibration are retained in `limits.json` and the control service.

## Run locally

Set a temporary admin token and an isolated data directory, then start the existing HTTP server:

```sh
ARIA_EXPERIMENT_ADMIN_TOKEN=local-dev-token \
ARIA_EXPERIMENT_DATA_DIR=/tmp/aria-experiment-data \
python3 legacy_ui_server.py --host 127.0.0.1 --port 8767
```

Open `http://127.0.0.1:8767/experiment/admin` and enter the same temporary token. The participant link generated by the admin page includes an unguessable access token in the URL fragment; the fragment is not sent in HTTP access logs.

For the Pi service, store `ARIA_EXPERIMENT_ADMIN_TOKEN` in `/etc/project-aria-experiment/admin.env` with mode `0600`. The systemd unit stores sessions in `/var/lib/project-aria-experiment`.

## Tests

```sh
python3 -m unittest discover -s tests -p 'test_experiment*.py' -v
python3 -m unittest discover -s tests -p 'test_legacy_ui.py' -v
python3 -m unittest discover -s tests -p 'test_servo_eye_only.py' -v
```

The experiment tests cover all 42 slots, constrained randomization, physical-state duplicates, consent, practice exclusion, persistence, CSV export, interruption, replay, and the mock HTTP routes. They do not actuate hardware.

The legacy `test_live_control.py` suite currently has 10 assertions that disagree with the present `live_control.py` eyelid and vertical direction mapping. The mock experiment does not change that controller or its calibration; those cases need a separate, physically confirmed calibration review.
